# Chùa Tịnh Tâm 3D

Không gian chùa 3D trên trình duyệt: dạo bước sân chùa, thỉnh Đại Hồng Chung, thả hoa đăng, dâng hương và tụng kinh cùng tiếng mõ, chuông.

- Mở trực tiếp file `index.html`, hoặc truy cập bản đăng trên GitHub Pages.
- Phím tắt: `W A S D` đi dạo · `F` tương tác · `V` thu gọn bảng · `H` ẩn giao diện.
- Đăng ký Phật tử và bản ghi âm tụng kinh chỉ lưu trên trình duyệt của người dùng, không gửi về máy chủ.

Xây dựng bằng Three.js, Tailwind CSS và Web Audio API — toàn bộ nằm trong một file HTML.
